## Overview

Enshrouded Building Calculator is a companion tool for the survival crafting game Enshrouded that calculates the total raw materials required to build any planned base structure, factoring in sub-crafted components like shaped stone and wooden planks. Input your floor plan and the tool outputs the full mining shopping list.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Enshrouded Building Calculator** delivers the features you need in a clean, intuitive package.

|---------|-------------|
| **Full BOM** | Complete bill of materials including all sub-crafted components |
| **Block Palette** | Select from all buildable block types with their material costs |
